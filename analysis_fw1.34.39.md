### 4.4 Что именно изменилось

Строковые таблицы между версиями **практически идентичны**. Ни одна значимая строка не была добавлена или удалена. Это подтверждает, что:

1. **Не добавлена поддержка новых устройств** — список SSD не изменился
2. **Не изменены сообщения об ошибках** — диагностика осталась прежней
3. **Изменения сконцентрированы в коде** — исправления багов, оптимизация логики
4. **+688 байт** — добавлено немного нового кода (возможно, дополнительные проверки или обработчики)

## 5. Golden Firmware (Recovery)

| Параметр | Значение |
|---|---|
| Файл | `RTL9210B_gd_v4.30.23.071922.bin` |
| Размер | 69 632 байт (68 KB) |
| Magic | `0x79817981` (отличается от основной FW: 0x97463136) |
| Дата | 19 июля 2022 (из имени файла) |
| Назначение | Recovery/bootstrap загрузчик |
| Код до | 0x00FFFF (полный 64 KB заполнен) |

Строки golden firmware:
- `Startup` — маркер загрузки
- `Incorrect sector index %x %x` — базовая обработка ошибок
- `USBSUSBC` — минимальный USB BOT
- `Realtek RTL9200         1.00` — идентификатор (RTL9200, не 9210!)

Golden firmware — минимальный загрузчик, записанный в защищённую область SPI-флеш. Он НЕ обновляется вместе с основной прошивкой и служит для восстановления в случае повреждения основной FW. Версия `v4.30.23` не менялась с июля 2022.

## 8. Рекомендации

### 8.1 Для обновления на v1.34.39

1. **Сделайте дамп** текущей конфигурации (кнопка Dump в UTHSB_MPtool)
2. Исправьте `UTHSB_MPtool_Lite.ini`:
   ```ini
   FwFlashBinSel=RTL9210B_v1.34.39.032625.bin
   ```
3. Используйте конфиг `RTL9210B_CG.cfg` (или ваш кастомный)
4. **Извлеките SSD** из корпуса перед прошивкой (рекомендуется)
5. Прошейте через UTHSB_MPtool_Lite

### 8.2 Что нового в v1.34.39

- **Дата сборки**: 26 марта 2025 (v1.34.29 была от 13 января 2025)
- **Прирост кода**: +688 байт — незначительное расширение функциональности
- **Характер изменений**: Полная перекомпиляция, 78% блоков затронуто
- **Строковые таблицы**: Без изменений — нет новых функций/устройств
- **Вероятно**: Исправления стабильности, оптимизация PCIe/NVMe обработки

### 8.3 Риски

- Прошивка подписана RSA — модификация бинарника невозможна
- При неудачной прошивке: recovery через замыкание CS#/VCC на SPI-флеш чипе
- Golden firmware (v4.30.23) не обновляется — recovery всегда доступен
- Откат: v1.34.29 включена в архив для возврата на предыдущую версию
